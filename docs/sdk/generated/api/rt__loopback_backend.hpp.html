   64 // A bounded, deterministic public HAL-v2 backend for sampled-I/O integration,
   65 // examples, and portable tests. Each configured dispatch opcode copies buffer
   66 // reference 0 to reference 1 and rewrites the sampled-frame destination
   67 // identity fields. It performs no allocation after construction.
   68 // Submit, poll and cancel use exclusive completion-slot ownership. Cancellation
   69 // can claim only a published batch; an in-progress submit or competing consumer
   70 // may make a bounded cancel scan return invalid_argument. A published injected
   71 // timeout remains held until cancellation. Repeated cancellation before polling
   72 // is idempotent. request_stop closes admission; callbacks already admitted may
   73 // finish. The caller quiesces callbacks before buffer changes, reset, shutdown,
   74 // reinitialization, move or destruction, as in Runtime's checked-stop lifecycle.
