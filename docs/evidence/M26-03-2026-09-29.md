## Implemented prototype

An optional configuring-only `golden::Physics` extension retains the default CPU
path and replaces the new variant's physics phase with an actual Runtime CUDA
device batch. The prototype owns bounded staging/borrowed device storage, ordered
upload/copy/kernel-or-Graph/download, one timeline and one in-flight slot. Its
simulator-only complete forwarding HAL table wraps the actual CUDA backend;
native resource construction retains native capability/replay behavior. Output
is validated before the existing stage publishes it. The new source includes an
integer SoA CUDA kernel and an incomplete CLI. The shared extension header is
included in the existing source-kit install inventory and provenance ledger.

The CLI explicitly rejects the not-yet-integrated fault and overload/recovery
campaigns. It must not be distributed or described as a finished CUDA kit.
