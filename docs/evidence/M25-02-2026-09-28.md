## Review, risks and rollback

The public SDK is additive. Review focused on borrowed state/name/context
lifetimes, exact raw statuses, capacity overflow and partial-estimate scope,
shutdown failure ownership, exception constraints, instance isolation, no
steady allocation and installed dependency isolation. Calling noexcept code
that allocates/blocks is still an application violation; the type constraint
cannot prove arbitrary user code is bounded. Guard users must keep Runtime
and every borrowed owner at stable addresses, call close for recovery, and
understand termination on unresolved destructor cleanup. Config/finalize still
allocate through raw Runtime. Hints never imply automatic recovery of side effects.

Rollback removes the optional header/kit/tests/docs and additive inventory
bindings while restoring the previous package contract. No production migration,
ABI bump, resource-policy default or release change is required. Release1.2.1,
portableRT0, C ABI v8/SONAME8/70exports/fingerprint0xd0e7a5a14bf35f97,
device ABIv1 and Apache2 remain protected.

Independent novice walkthrough, physical CUDA/XDMA/combined hardware, RT1/RT2,
controlled performance, Unreal, signing/release/deployment remain UNPERFORMED.
Four later M25 batches and six M26 batches remain after this batch integrates.
