## Ordering and regression

`finish_batch_slot` released the ordinary executor graph before decrementing
outstanding work and publishing Free. `complete_external` can finish the final
phase and let `step()` return before the completion thread resumes. A host stop
can then observe Owned and call backend cancellation for the completed batch.
This source interleaving is established; the original failed run was not
instrumented, so its precise interleaving remains an inference.

The private allocation-free template extracts only ordinary slot retirement.
It snapshots phase/backend and atomically claims graph release, decrements
outstanding work, publishes Free, wakes the backend lane, and then completes the
graph using captured metadata. It never touches the slot after Free publication.
Timeline and completion accounting still precede retirement. Active-rate terminal
and quarantine branches are unchanged; pending stop/timeout/early-completion
and graph-release ownership rules remain intact. No cancellation suppression,
new resource, public interface, allocation, polling or deadline change is added.

Four deterministic tests instantiate the actual production helper. They force
host-stop observation exactly at graph publication, reuse immediately at that
boundary, reuse after Free but before graph publication, and prior graph release
by stop. A behavior-equivalent original-order extraction fails two tests with
four assertions: outstanding remains one, cancellation is observed, the slot is
still Owned at publication and a reused occupant is overwritten with Free.
The two control tests pass. Negative control exit 1; log
`/tmp/m2305r-negative.log`; extraction patch SHA-256
`886ecd3b646c7bc9af71e05143455cdfe8a75882c78f3916ce239b22a23aeaac`.
This executable compiles the production header and links the unchanged baseline
Runtime library; later full builds exercise the modified production call site.
The existing public two-owner, eight-lifecycle, 128-frame test is unchanged.
