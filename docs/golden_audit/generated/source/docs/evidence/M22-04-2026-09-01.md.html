## Changed and preserved invariants

M22-04 adds the optional source-only `<rt/live_control.hpp>` entrypoint. It
defines caller-owned fixed storage, a 32-byte canonical envelope, compile-time
application traits, exact host/rate record builders, and bounded transactional
decode. The helper never stages, retries, retargets, advances a producer
sequence, hides an admission result, starts a thread, performs I/O, or owns
teardown. The raw M22 API remains directly usable.

The retained empty raw `clear_fault` form remains valid. The only raw-path
repair also permits a nonempty canonical typed clear-fault payload. Numeric
values, record layouts, storage ownership, admission semantics, actions,
checkpoints, and replay formats are unchanged.

Stable C ABI v8 remains exactly 70 exports with fingerprint
`0xd0e7a5a14bf35f97` and SONAME 8. Device ABI v1, extension ABI v1, HAL tables,
Runtime/profile/artifact/telemetry schemas, release 1.2.1, license, support and
qualification matrices, and all prior evidence remain unchanged. Runtime
rollback owns only the Runtime generation; it does not reverse application,
backend, process, or physical effects.
