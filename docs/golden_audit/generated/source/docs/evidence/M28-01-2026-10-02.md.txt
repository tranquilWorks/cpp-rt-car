## Cause and correction

The unchanged public entry point deterministically exposes a replacement reader
while its calibration is held: the new callback is called twice where only its
single calibration entry should be visible (exit41). Initialized TSan independently
reports concurrent initialization writes to HighResClock::tsc_reader_. A separate
concurrent SimCore-owner baseline also reports this same global data race. No
fixture construction lock is used for that control.

Initialization calibrates under a writer-only mutex, then publishes an even
generation with atomic reader/frequency/epoch fields. Sequentially consistent
operations make one equal-even snapshot consistent; readers encountering a
publication immediately use the existing monotonic fallback. Read paths never
take the writer mutex or retry the snapshot. The pre-existing monotonic CAS loop
remains. Failed samples disable only their own generation; stale readers cannot
disable a newer initialization. Failed calibration disables TSC, and init never
resets the shared monotonic floor. Calibration remains50ms and drift bound1ms.
Generation exhaustion disables TSC instead of reusing an identity.

Injected function pointers remain borrowed. Concurrently used callbacks must be
thread-safe, valid throughout outstanding calls, and non-reentrant into init or
set_tsc_reader. No plugin lifetime management or physical timing guarantee is
added. This repairs the shared clock, not every experimental SimCore global policy.
The owner test uses the existing FMA-off configuration and retains caller-thread
arena construction/run/destruction. Broader global FMA-policy concurrency is not
qualified or changed by this batch.

disabling warnings. The first owner link lacked the existing experimental platform

quoted includes; a complete unchanged include-tree copy fixes the diagnostic setup.

clock global; the diagnostic classifier was corrected and the original report kept.

supported public Runtime targets; full-owner tests stay in the source build. No old
package test, test count, requirement or default installation is weakened.
