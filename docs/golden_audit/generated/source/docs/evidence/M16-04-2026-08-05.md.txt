## Independent system-risk review repair

The independent review found one material medium-severity bounded-execution
failure in `Runtime::Impl::run_active_step()`. Range aggregation was enabled
for late skip/hold work only after every optional domain had already shed. If
optional work remained active but its own late action omitted it, a large
window performed one loop and one telemetry publication attempt per optional
release, contrary to the batch bound against work proportional to omitted
supercycles.

The repair makes already-shed optional releases and active optional late
skip/hold releases independently eligible for aggregation up to the next
mandatory or executable total-order barrier. Mandatory late omissions remain
unaggregated while a transition can still affect optional work, preserving
threshold and same-time ordering semantics. The new permanent test
`RateShedding.LargeOptionalLatePrefixAggregatesBeforeShedThreshold` retains a
mandatory domain, holds the shedding streak below threshold, and verifies
10,000 late optional releases as one singleton plus one exact 9,999-release
range with no callback, transition, loss, or shed disposition.
